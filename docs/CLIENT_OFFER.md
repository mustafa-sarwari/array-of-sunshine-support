# Customer-support customization service

The portfolio app demonstrates a real React/TypeScript + Node.js + SQLite implementation:
password sign-in, owner authorization, FAQs, visitor conversations, inquiries and human handoff.
Its default assistant uses approved FAQ matching, with no paid AI model. It runs locally.

Customization can cover branding, approved answers, inquiry fields and website embedding.
A project quote must specify deliverables, revisions, acceptance tests, deadlines and payment.
Deployment and paid model integration are separate work; the AWS scaffold has not been deployed.
Hosting and any paid AI usage belong in the client's account under an agreed budget.
Budget alerts notify the client and do not enforce a hard spending cap. No production cost or
AI answer-quality guarantee is made from this local sample.
